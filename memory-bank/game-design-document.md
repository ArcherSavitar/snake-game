# 贪吃蛇游戏设计文档

## 1. 项目概述

| 项目 | 内容 |
|------|------|
| 项目名称 | Snake Game (贪吃蛇) |
| 类型 | 移动端休闲游戏 |
| 技术栈 | HTML5 Canvas + JavaScript + Android WebView |

## 2. 游戏玩法

玩家通过控制蛇的移动方向，使其吃掉食物并获得分数。蛇吃到食物后身体变长，撞到墙壁或自身则游戏结束。

### 操作方式
- **键盘控制**: 方向键 (↑↓←→) 或 WASD
- **触摸控制**: 屏幕下方的虚拟方向键 (仅触屏设备显示)
- **暂停**: 空格键 或 暂停按钮

## 3. 核心机制

### 游戏参数
| 参数 | 初始值 | 范围 |
|------|--------|------|
| 网格大小 | 20×20 | 动态调整 (最小 8×8) |
| 初始速度 | 120ms/格 | 随分数递减 (最低 60ms) |
| 得分增量 | +10分/食物 | 速度同时加快 4ms |

### 碰撞检测
- **墙壁碰撞**: 蛇头超出边界 → 游戏结束
- **自身碰撞**: 蛇头撞到身体 → 游戏结束
- **食物碰撞**: 蛇头与食物坐标重合 → 得分 + 生成新食物

## 4. UI 设计

### 页面布局
```
+----------------------+
|       贪吃蛇         |
+----------------------+
|  得分: 0   [开始][暂停][重开] |
+----------------------+
|                      |
|      游戏画布        |
|      (Canvas)        |
|                      |
+----------------------+
|    ↑ ← → ↓ (触屏)    |
+----------------------+
```

### 视觉风格
- **背景色**: #111 (深色)
- **文字色**: #eee (浅色)
- **主色调**: #2d7ef7 (蓝色)
- **蛇头**: #2ecc71 (绿色)
- **蛇身**: #27ae60 (深绿)
- **食物**: #e74c3c (红色)

### 响应式设计
- 竖屏: 垂直布局
- 横屏: 水平布局，隐藏标题
- 小屏 (<400px): 缩小控制按钮和字体

## 5. 控制流程

```
[初始状态] --点击开始--> [运行中] --点击暂停--> [暂停中]
     ↑                         |                    |
     +-----------重开----------+-------继续--------+
```

### 状态说明
| 状态 | 描述 |
|------|------|
| initial | 游戏未开始，显示开始按钮 |
| running | 游戏进行中 |
| paused | 游戏暂停 |
| gameOver | 游戏结束，显示重新开始 |

## 7. 技术特点

- **混合开发**: WebView 加载本地 HTML
- **自适应画布**: 根据容器尺寸动态计算网格
- **防抖处理**: UI 按钮操作防抖 (100ms)
- **无障碍支持**: 触屏设备自动显示虚拟按键
- **全屏体验**: 隐藏系统标题栏和缩放控件
